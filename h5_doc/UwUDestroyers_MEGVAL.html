1. Megvalósítási dokumentáció

Fejlesztési folyamat

A fejlesztés a dokumentáció írásával párhuzamosan történt, a Scrum módszertan alapján, egy hetes sprintekkel és meetingekkel. A fejlesztés során az elkészült részek folyamatosan tesztelve lettek unit, ill. integrációs tesztekkel.

Architektúra megvalósítása

Az architektúra három részbe lett szervezve

Megjelenítési réteg (UI)

4 fő oldalból áll:

• Home page: Az alkalmazás fő képernyője, itt látszik a bejelentkezett felhasználó, és innen érhetőek el a többi képernyők.

• Recept page: Itt lehet létrehozni új receptet és megnyitni már létező receptet.

• Refrigerator page: A virtuális hűtő, ahol a meglévő alapanyagokat lehet tárolni.

• Shopping List page: A bevásárló lista elkészítése a szükséges alapanyagok alapján.

Alkalmazási réteg (üzleti logika)

Kontrollerek és szolgáltatások (felhasználó, recept, hűtő, bevásárló lista)

Adatkezelési réteg (adatbázis)

2 fő komponense:

• Adatbázis

• ORM

Tervezési minták

• MVC: A frontend és a backend el van különítve

• Repository: Adatbázis műveletek egységesen vannak kezelve

• Service layer: Üzleti logikák centralizálva vannak

• DTO: Entity és reprezentációs modell elkülönítése

Használt technológiák

Frontend technológiák:

• React 18+ - Komponens alapú UI fejlesztés

• TypeScript - Típusbiztos JavaScript

• Axios - HTTP kliens

• React Router - Oldal navigáció

• Material-UI - Design rendszer

Backend technológiák:

• C# - Programozási nyelv

• ASP.NET Core - Alkalmazás keretrendszer

• Entity Framework Core - ORM megoldás

• JWT Bearer - Autentikáció

• Swashbuckle - API dokumentáció

Adatbázis:

• MySQL 8.0 - Relációs adatbázis

• Pomelo Entity Framework - MySQL provider
